# 系统设计与算法

## 代码边界

`app.py` 负责 HTTP 参数、图片解码校验、任务编号、报告文件和同源静态界面；`analysis.py` 负责算法编排与统计，不依赖 FastAPI；匹配器只返回点对及实际检测点数。异常和缺失测量分别表达，不通过模拟数据补齐。

所有本项目路径由源码位置或 `.env` 决定。图片在内存中解码，输出使用随机任务 ID 和固定文件名，不采用上传者提供的文件名。下载路由只接受 32 位十六进制任务 ID 和三个指定文件名。

同一进程一次处理一个分析任务；额外请求返回 429。重型匹配在工作线程运行，研究模型由锁保护。该设计面向本地实验，不是多租户线上任务系统。

## 四区域位移

1. 校验两张图像尺寸一致，以宽高的整数中点分成四区；奇数尺寸的边缘像素不会丢失。
2. 在对应区域独立提取、匹配特征。SIFT 使用双向最近邻与 0.75 比率检验；SuperGlue 使用原研究模型的匹配输出。
3. 对点对计算向量 `d = target - reference`。以向量中位数为中心，对向量残差应用 `max(2 px, median + 3 × 1.4826 × MAD)` 阈值，去除明显离群匹配。
4. 过滤后至少 6 个点对才将区域标为 `measured`，否则统计量为 `null`。
5. 位移幅值为 `sqrt(dx² + dy²)`；全图平均、最大、最小和标准差直接从所有有效区域的点对计算。方向单独报告 `median_dx / median_dy`。

这种一致性过滤更适合区域内近似一致的运动，可能滤掉真实的局部非均匀变化。四区独立匹配还会丢失跨分区边界的特征对应。它是本次整理版的可解释研究基线，需要进一步以标注数据比较不同过滤和分区策略；不是结构形变估计的完整解决方案。

## 原研究模型适配

适配器从外部研究目录只读加载模型类，保留原项目的 SuperPoint 配置、SuperGlue 双精度与描述子缩放约定。使用全部检测点，不再为了使点数相等而截断两张图的关键点。

原训练版 SuperGlue 的 `forward` 同时要求 `all_matches` 并计算损失。推理适配器为这条未使用的损失分支提供一个固定索引占位；返回的 loss 不用于测量、训练或性能评估，预测匹配使用模型真正输出的 `matches0`。该接口约定只适用于本地研究分支。

权重使用 `weights_only=True` 读取，要求 PyTorch ≥ 2.6。外部源码仍是会执行的 Python 代码，只应配置自己已经检查的研究目录。本仓库不会联网下载或自动替换模型。

## 日期趋势

每张对比图始终与同一基础图比较。对每个区域，将有效日期距离首个对比日期的天数作为 x，平均位移幅值作为 y，用一阶最小二乘拟合 `y = a×x + b`，斜率单位为 px/天。

至少三个有效日期才拟合；缺失点不插值、不补零，曲线缺口断开。斜率大于阈值提示幅值增加，小于负阈值提示幅值减小，其余表示未见明显线性趋势。阈值是实验参数，没有工程安全依据。
