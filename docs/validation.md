# 整理预览验证记录

## 本机实测

已验证主机：Windows，Python 3.14.0；NumPy 2.4.4、OpenCV headless 4.13.0.92、FastAPI 0.121.3、Uvicorn 0.38.0。原研究权重推理使用 PyTorch 2.9.1+cpu。时间与耗时是当前本机记录，不作为跨设备性能承诺。

| 检查 | 结果 |
| --- | --- |
| 自动化单元 / API 测试 | 11 项通过 |
| 已知合成平移 dx=4、dy=3 | 理论幅值 5 px |
| SIFT CPU 基线 | 四区有效，612 个参与统计的点对，均值约 5.0012 px |
| 本地原 SuperGlue 权重 | 四区有效，338 个参与统计的点对，均值约 5.0184 px；该次约 3.23 秒 |
| 无纹理图 | 无法测量，位移为 null，不是 0 |
| 尺寸不一致 / 无效图 / 超限图 | 拒绝无效输入 |
| 重复 / 无效 / 早于基础的日期 | 拒绝输入 |
| 非顺序批量图像与日期 | 图像和日期正确配对排序，5 / 10 / 15 px 的样本顺序正确 |
| 不等日期间隔趋势 | 按真实天数拟合，缺失值不补零 |
| 模型未配置 | 返回 503，不伪造成功结果 |
| JSON / CSV / 匹配图 | 可读取；只允许指定任务文件 |
| 桌面浏览器 | 无 JavaScript 异常，单次与时序流程通过 |
| 390 px 手机视口 | 无文档级横向溢出 |

自动化命令：`python -m unittest discover -s tests -v`。
